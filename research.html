# Chae Won Lim — Multi-page Portfolio GitHub Pages-ready static site. ## Pages - `index.html` — Home - `about.html` — About, education, credentials (TOEIC grouped here; no separate TOEIC page) - `research.html` — Research - `creative.html` — Creative projects - `gallery.html` — Photography gallery - `publications.html` — Publications - `toolbox.html` — Technical + creative tools - `contact.html` — Contact There is **no Experience page**. ## Deploy to GitHub Pages Upload all files and the `assets/` folder to the repository root, then enable GitHub Pages from the main branch/root. ## Notes - Main visual uses the public LinkedIn profile badge and therefore uses the LinkedIn profile photo when LinkedIn loads successfully. - Behance gallery images are loaded from the public Behance CDN.
